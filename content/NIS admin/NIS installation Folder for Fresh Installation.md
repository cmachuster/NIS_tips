
To help during a fresh installation, it is possible to download and used a "NIS_install" folder [here](attachments/NIS_install.zip) 

This folder is to be place in the Nikon folder C:\Nikon Service and contains a macro that loads a default clean Layout and put in place different setting of NIS.
For those using GA3 some homemade functions are proposed to help save files in batch more easily.
