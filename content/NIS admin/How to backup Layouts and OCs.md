In NIS it is possible to save the visual organization of the software, the layouts, and the different [[General rules for OCs|Optical Configuration]] as `.xml` files in order to reload them later or to share them on other machines.

This backup files can be reloaded manually or through a command/macro (see [[Restore Macro]]) sets as a button or at NIS startup (see [[Run Macro on Events]]).

## saving Layouts
The option to save the Layouts is in the Layout Manager Window. It can be found by going in the menu Edit > Options then choosing in the left side of the open window the "Layout Manager"
![[Layout Manager_annotated.png|400]]

The Layouts can be saved as a `.xml` file or imported from it using the top icons : ![[Layout Manager_annotated_zoomed.png|100]]

## saving Optical Configurations
To save the OCs, go to Calibration > Optical Configurations...
![[OC_saving_1.png|300]]

From the "Optical configurations" window, you can Import / Export from/to a `.xml` file
![[OC_saving_2_annotated.png|400]]

When Exporting, you can choose which OCs will be saved in the `.xml` file.
![[OC_saving_3.png|300]]
>[!warning] from here you will have the choice to save OCs from different lightpaths
