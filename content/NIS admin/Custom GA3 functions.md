If the customer is using GA3 (General Analysis 3) please check the "GA3_functions" folder and it Readme file.

The folder contains some extra GA3 functions (mainly to rename files for batch analysis) that are missing per default

The folder "UserGA3" needs to be copied to the "Laboratory Imaging" folder that is per default located here :
`C:\ProgramData\Laboratory Imaging`

>[!tip] use the shortcut provided to reach it faster
